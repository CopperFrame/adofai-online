# Changelog / Histórico de mudanças

Each version has its own page under [Releases](https://github.com/CopperFrame/adofai-online/releases) with the install files.
Cada versão tem a própria página em [Releases](https://github.com/CopperFrame/adofai-online/releases), com os arquivos de instalação.

## 0.2.8
- Fixed the empty level list after a match (the mod now reads local and Workshop levels even when the game returns to a featured category). / Corrigida a lista de fases vazia depois da partida.
- Downloads that receive no data for 30 s now fail with a clear message instead of staying at 0%. / Downloads parados por 30 s agora falham com mensagem clara.
- Touches and keys no longer go through the mod's screens to the level selector behind them. / Toques e teclas não atravessam mais as telas do mod até o seletor de fases.

## 0.2.7
- Optional room password, host **Ban** (by IP) and a **Report** button. / Senha de sala opcional, **Banir** (por IP) e botão **Denunciar**.
- Chat rate limit (anti-spam) and an optional swear-word filter (Options; extra words in `AdofaiOnline-lang/filter.txt`). / Anti-spam no chat e filtro de palavrões opcional.
- README: "What the room server sees". / README: "O que o servidor da sala enxerga".

## 0.2.6
- Installer self-check (game, BepInEx, mod file, Windows blocking, antivirus detections), updates a BepInEx that is too old. / Autoverificação no instalador; atualiza BepInEx antigo.
- New `Diagnose-ADOFAI-Online.bat` writes a report to send when the Online buttons do not show up. / Novo `Diagnose-ADOFAI-Online.bat`.
- Fixed texts flashing in Portuguese when clicking on the room screen; picker buttons and tags fixed. / Corrigidos textos piscando e botões do seletor.

## 0.2.5
- Installed Workshop levels are recognized (the picker no longer starts empty). / Fases da oficina instaladas são reconhecidas.
- New level picker with artwork, Workshop/Local tags, search, filters, counter and letter dividers. / Novo seletor de fases com arte, filtros, contador e divisores.

## 0.2.4
- Level queue (up to 8 levels; the next one is picked when a match ends). / Fila de fases.
- Room screen grouped into code/server, Level and Modifiers. / Tela da sala em grupos.
- Language files: add your own language without touching the code (`AdofaiOnline-lang/<code>.txt`). / Idiomas por arquivo.

## 0.2.3
- Easy installer (`Install-ADOFAI-Online.bat`) with checksum verification. / Instalador fácil com checksum.
- Options screen (language, servers, update check) and keyboard/controller navigation. / Tela de Opções e navegação por teclado/controle.
- Notice of a newer version, and of mod parts that a game update broke. / Aviso de versão nova e de patches quebrados.

## 0.2.2
- Fixes to English/Korean translations in the community level browser and level selector. / Correções de tradução.

## 0.2.1
- Korean (한국어) support. / Suporte ao coreano.

## 0.2.0
- Screens in English and Portuguese, following the game language. / Telas em inglês e português.

## 0.1.0
- First release: rooms for up to 4 players, ghosts with names, spectator mode, chat, Immortal/Speed modifiers, levels from ADOFAI.gg/TUF downloaded automatically. / Primeira versão.
